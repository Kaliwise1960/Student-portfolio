## Project Overview
This website is a multi-page student academic portfolio and interactive student management platform designed and built using HTML5, CSS3, and JavaScript for the COS 106 practical term project[span_0](start_span)[span_0](end_span).

- `index.html`: Homepage featuring student profile, biography, navigation menu, and audio welcome element[span_1](start_span)[span_1](end_span).

- `projects.html`: Portfolio grid displaying cybersecurity and web development projects with live and code repository links[span_3](start_span)[span_3](end_span).
